# Kotlin Learning Path

Este repositorio es un registro activo y estructurado de mi progreso diario en el lenguaje de programación Kotlin, 
Mi objetivo con estos desafíos es ir más allá de la sintaxis: busco afianzar la creación de código seguro, el diseño de arquitecturas de software sólidas y las ventajas de un lenguaje de tipado estático moderno.

## Estructura del Repositorio

El código está organizado de manera semántica según el concepto o paradigma aplicado:

* **`01_Bases_y_Control_Flujo/`**: Variables (`val` / `var`), inferencia de tipos, manejo seguro de nulos y estructuras de control avanzadas (`if` y `when` como expresiones).
* **`02_Funciones/`**: Declaración de funciones, parámetros con valores por defecto y funciones de expresión única.
* **`03_POO_Basica/`**: Clases, constructores primarios, encapsulamiento y el uso de *Data Classes* para el modelado eficiente de datos.
* **`04_Colecciones/`**: Estructuras de datos, listas y operaciones funcionales (lambdas) para la manipulación de información.
* *(Módulos en expansión)*

## Tecnologías y Entorno
* **Lenguaje:** Kotlin
* **Entorno / IDE:** IntelliJ IDEA (Community Edition)
* **Enfoque:** Aplicaciones de consola interactivas, código conciso y robusto, totalmente libre de excepciones por punteros nulos (NullPointerExceptions).

## Filosofía de Trabajo
Cada archivo y ejercicio de este repositorio representa un commit hacia la escritura de código limpio, idiomático y modular. El enfoque principal está en aplicar buenas prácticas de la industria, como la validación estricta de entradas y el aprovechamiento de las herramientas modernas que ofrece Kotlin frente a lenguajes más tradicionales.
